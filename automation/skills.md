## Recurring themes and opinions

These are where the good posts come from — a position, defended with code.

- Frameworks are details. Boundaries and dependency direction decide whether a codebase
  survives its third year.
- Test pyramids over test icebergs: fewer, stronger tests, and honest doubles.
- Micro-frontends pay for themselves at **organisational** seams, not technical ones.
- UX-driven development: the component API is a user-experience decision.
- A design system is a contract; tokens are how design and code sign it.
- Accessibility and performance are correctness, not polish.
- Migrations are the real curriculum — AngularJS to Angular, Redux to signals, Xamarin to
  .NET MAUI, Ionic 5 to current. Write the friction, not the highlight reel.
- SOLID and clean code demonstrated on code that actually needed fixing.
- AI engineering as a practice, not a novelty: GitHub Copilot, Claude Code, MCP servers,
  repository skills, agentic workflows. What genuinely changes a team's day, and where the
  approach falls over.

## Voice

- First person, direct, practical: "I", "we", "let's".
- Concrete over abstract — name the file, the parameter, the API, the failure.
- Bold key terms. Numbered steps where order matters. Short paragraphs.
- State the trade-off out loud. Never imply a hard step was painless.
- No marketing register. Banned: "in today's fast-paced world", "revolutionary",
  "game-changing", "unleash", "seamless", "delve".

## Non-negotiable rules

- **No employer or client names.** No company names, product names, internal acronyms or
  project codenames. Describe the domain generically — "a regulated onboarding funnel",
  "a global settlements team".
- **No invented numbers.** No fabricated team sizes, timelines, percentages, benchmarks,
  incidents, or quotes from colleagues. If a number is not known, do not write one.
- **No personal data and no contact details** — no address, phone, email, date of birth, or
  anything beyond a professional first-person voice.
- **Nothing private.** If it is not already public on a professional CV or blog, it does not
  go in a post.
- **No official third-party logo files.** Artwork redraws a flat, stylised motif for the
  subject; it never embeds a vendor's asset.
